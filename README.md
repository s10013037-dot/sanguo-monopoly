# 三國萌將大富翁

使用 React、TypeScript、Vite 製作的繁體中文瀏覽器棋盤遊戲。無需帳號、伺服器或 API 金鑰，所有插畫與資產都隨專案提供。

## 在瀏覽器遊玩

建議使用 Node.js 22 或 24（本次驗證為 24.19.0）。

```bash
npm ci
npm run dev
```

本機瀏覽器開啟終端顯示的網址（預設 http://localhost:5173/sanguo-monopoly/）。若在雲端工作區，請在平台的連接埠／Ports 功能轉送 **5173**，再開啟該平台提供的網址。

```bash
npm run build   # TypeScript 檢查與正式版打包到 dist/
npm run preview # 正式版預覽，預設 4173 連接埠
npm test        # 遊戲規則與存檔測試
npm run test:e2e # Chromium 真實瀏覽器測試
```

瀏覽器測試預設使用 `/usr/bin/chromium`；其他系統可安裝 Chromium 並以 `CHROMIUM_PATH` 指定執行檔。亦可執行 `npx playwright install chromium`，並將 `CHROMIUM_PATH` 指向下載的 Chromium 執行檔。

## 玩法

- 選擇劉備、曹操、孫權或董卓，與另外三位電腦主公輪流行動。
- 按「擲骰子，出發！」逐格移動。結算後按「結束回合」，電腦會自行完成回合。
- 24 格棋盤包含招賢城池、補給、奇遇、戰場與桃園起點。
- 城池自動招募未擁有的武將，消耗標示的招募身價；缺錢時改為協助城務。每位主公可獨立招募同一位名將。
- 軍隊戰力為基礎 20 加上所有武將戰力；戰鬥每輪造成戰力 55% 的傷害（四捨五入），守軍存活時反擊 24 點。勝利獲得 280 金，失敗最多損失 150 金。「跳過戰鬥」只快轉，不改變結果。
- 十二輪（48 回合）後，以金錢加上已招募武將的身價排名；平手依玩家順序排列。
- 每次狀態變化都儲存至瀏覽器 localStorage，重新整理會接續行軍、電腦回合或戰鬥。同一瀏覽器、同一網站保留一份存檔；清除網站資料會移除進度。不支援跨裝置同步，也請避免同時開多個遊戲分頁。
- 音效預設關閉，可在右上角開啟；目前提供擲骰提示音。

## 專案結構

- `src/game.ts`：獨立的回合、事件、招募、戰鬥與存檔規則。
- `src/main.tsx`：棋盤、主公與武將 UI、動畫計時、自動儲存。
- `src/style.css`：山水棋盤、CSS Q 版主公肖像、響應式介面與減少動態效果支援。
- `src/game.test.ts`、`tests/game.pw.ts`：規則測試與瀏覽器整合測試。

第一版使用自製 SVG 山水、CSS 主公肖像與系統 emoji 武將圖示；emoji 外觀依作業系統而異。尚未加入線上多人、土地買賣或跨裝置存檔。


## GitHub Pages 自動發布

網站子路徑固定為 `/sanguo-monopoly/`。儲存庫的 **Settings → Pages → Source** 請選擇 **GitHub Actions**。

1. 將部署設定的 Pull Request 合併到 `main`。
2. 到 **Actions → Deploy game to GitHub Pages** 查看最新執行。
3. `build` 與 `deploy` 都顯示綠色勾號後，點開 `deploy` 的網站連結，或到 **Settings → Pages → Visit site**。
4. 預期網址為 https://s10013037-dot.github.io/sanguo-monopoly/ 。首次發布可能需要幾分鐘才可瀏覽。

往後每次更新 `main` 都會自動安裝依賴、執行規則測試、建置並發布 `dist/`。PR 只執行測試與建置，不會部署。也可在 Actions 的 **Run workflow** 選擇 `main` 手動重試。

流程採用 GitHub 官方 Pages Actions，固定至官方範例的完整 commit SHA，並使用 `github-pages` 部署環境與 GitHub 自動提供的權限，不需要設定個人存取權杖。

## V2：真正 WebGL 3D 微縮棋局

本版以 **Three.js** 渲染真實 3D 網格，包含正交相機、環境光、方向光與柔和陰影；棋盤不是 CSS 變形或平面圖片。24 格順序、金錢、招募、戰鬥、電腦回合和既有 localStorage 存檔格式保持不變。

### 3D 操作

- 滑鼠左鍵拖曳旋轉、滾輪縮放；右鍵拖曳平移。手機單指旋轉、雙指縮放或平移。
- 也可用上方按鈕放大、縮小、重設視角或「聚焦主公」，「行軍鏡頭跟隨」預設關閉以避免搶走手動鏡頭。
- 移到地形平台會發光；點擊平台，或使用「探索地點」選單，查看格子名稱、類型與規則。
- 畫質選擇會儲存在瀏覽器：標準提供陰影、較多森林與最高 1.5 倍像素比；低畫質停用陰影、降低森林數、像素比限制為 1，並以約 30 FPS 為目標限制重繪。
- 金色立體光圈標示目前行動主公；戰鬥時轉為紅色並顯示戰鬥提示，招募成功會有金色粒子。
- 武將卡片現在可點擊，顯示兵種、稱號、戰力與招募身價。兵種只是背景資訊，未新增兵種相剋規則。

### 行軍與備援

每格 3D 行軍約 800 毫秒，包括轉向、交替手腳、起伏與最後落地；由渲染器完成該格動畫後，才提交一次規則更新。背景分頁停止畫面重繪時，不會跳過尚未完成的行軍格來結算抵達事件。重新整理或切換畫質會從已儲存的位置接續；重開遊戲會使用同一位主公。

若 WebGL 無法啟動、模組載入失敗或發生 context loss，會顯示原因並切換到仍可完整遊玩的 2D 棋盤。也可主動點選「2D 備援」。瀏覽器需支援 WebGL2；可檢查 Chrome 的「設定 → 系統 → 在可用時使用圖形加速」。減少動態效果設定會停用裝飾擺動與公仔擺腿，但仍保留逐格位移與回合。

### 建模與效能

- `src/three/models.ts`：自行建立的大頭全身公仔、盔甲、披風、冠帽、佩劍、城池與地形模型。使用共享幾何體／材質，靜態部分依材質批次合併。
- `src/three/world.ts`：Three.js 場景、raycast、相機、動畫與 GPU 資源釋放。森林使用 InstancedMesh；單一陰影光源，標準陰影貼圖 1024。
- `src/WorldBoard.tsx`：畫質、格子查詢、動態載入與錯誤備援；`src/Board2D.tsx` 為 SVG 備援棋盤。
- `src/game.ts`：獨立且保持不變的遊戲規則，不依賴 Three.js。

所有模型由程式在本機產生，沒有付費服務、外部模型下載或 API 金鑰。Three.js 為 MIT 授權。3D 模組僅在進入棋局時載入；其壓縮前約 600 KB，首次載入會比舊版多一些時間。V2 的介面肖像與武將卡片為 SVG／emoji；V3 已改為由對應 3D 模型擷取的頭像。

目前優先提供輕量的程式化公仔，尚無手繪貼圖、骨骼動畫檔、電影級景深或完整動作捕捉。相容性已用 Chromium 的軟體 WebGL 與手機尺寸測試；實際手機 GPU 的幀率與發熱仍需以裝置確認。

### 驗證

```bash
npm ci
npm run build
npm test
npm run test:e2e
```

Playwright 使用 Chromium 軟體 WebGL flags，除原有流程之外，驗證真實 WebGL2 canvas、四位模型四肢與錯位站位、六點跨轉角的 3D 位移與擺腿、到站招募、存檔、手機尺寸、畫質、武將詳細資訊及 WebGL 啟動／context loss 備援。這不是實體手機 GPU 效能測試。

合併 PR 至 `main` 後，既有 GitHub Pages 工作流程會自動部署 `/sanguo-monopoly/`；不需額外服務或金鑰。

## V3：萌將公仔工坊

V3 沿用 V2 的 24 格 WebGL 棋盤、回合與存檔格式，只擴充人物、動畫與展示。這是自行製作的程式化公仔，尚不是專業雕刻、手繪貼圖或動畫師製作的商用美術資產。

### 實際完成的角色

- **劉備**：翠綠長袍、玉冠、短鬚、披風與雙股劍；勝利時雙手舉劍。
- **曹操**：高冠與冠翼、寬肩玄甲、黑披風、銳眉與佩劍；勝利時向前指劍。
- **孫權**：碧玉金冠、白袖輕甲、金棕配色與佩劍；待機時微微轉頭，勝利時舉手號令。
- **董卓**：較壯身形、重肩甲、紫黑甲與紅披風、重型霸刀；勝利時高舉武器。
- **趙雲**：白銀盔甲、盔羽與藍披風、龍膽亮銀槍。
- **關羽**：長鬚綠袍、頭巾、青龍偃月刀。
- **張飛**：濃黑鬍鬚、厚甲、頭巾飄帶、丈八蛇矛。
- **呂布**：黑紅金甲、雙長翎、方天畫戟。
- **周瑜、張遼、黃忠、馬超**：同風格通用甲士，介面明確標示專屬造型待擴充。黃忠的專屬弓尚未製作，不宣稱通用佩劍是其正式代表武器。

### 圖鑑與武將展示

1. 點右上方書本按鈕「主公圖鑑」，可切換四位主公、查看全身模型及勢力、初始能力和介紹。
2. 點已招募武將卡片，可查看該武將的 3D 公仔、武器、兵種、戰力、身價與既有戰力加成。沒有新增獨立技能或兵種相剋規則。
3. 拖曳／單指旋轉，滾輪／雙指縮放，也可使用放大、縮小與重設按鈕。可播放待機、勝利與招募登場。
4. 展示期間棋局暫停，關閉後從原位置接續；展示動作只修改視覺關節，不會擲骰、扣款、招募或重複觸發事件。Esc 可關閉，Tab 會留在展示視窗。
5. 卡片與主公介面頭像由同一套 3D 模型擷取 PNG，並依角色 ID 快取；不是為每張卡片建立常駐 WebGL 場景。

### 動畫與效能

共用動畫包括呼吸、眨眼、輕微擺臂、披風擺動、交替行走、到站落地、招募登場與角色差異化勝利姿勢。原本每格行軍的完成通知保持單次提交；招募後棋盤短暫顯示該武將的登場公仔與既有金色粒子，戰鬥勝利後主公慶祝。

棋盤角色使用較低細節，標準展示使用較細的曲面、羽翎與髮束；低畫質展示沿用低細節。四位玩家各有勢力色腳環，當前玩家另有金色高亮；可關閉頭頂姓名。

展示分頁切換共用一個 renderer；關閉展示時停止動畫、移除事件與 ResizeObserver、釋放模型／材質／幾何體，並主動釋放 WebGL context。縮圖以短暫共用 renderer 批次產生，完成後釋放，只保留最多十二位角色的 PNG 字串。無 WebGL 時，頭像顯示文字標記，仍可閱讀人物資料並返回原有 2D 棋盤。

### 擴充位置

- `src/characterCatalog.ts`：角色 ID、外觀描述、兵種與武器等展示資料；遊戲數值仍讀取 `src/game.ts`。
- `src/three/characters.ts`：共用公仔部件、八種專屬輪廓、武器與純視覺關節動畫。
- `src/three/showroom.ts`：獨立展示場景及旋轉、縮放、角色切換與資源釋放。
- `src/three/thumbnails.ts`：同模型頭像的批次擷取與有界快取。
- `src/CharacterGallery.tsx`：圖鑑及已招募武將展示，沒有遊戲規則寫入介面。

擴充專屬外觀時，為既有角色指定新輪廓／武器建模即可；無需改動存檔或戰鬥數值。原有 GitHub Pages base 與自動部署流程保持不變，合併 V3 PR 後即可自動發布。

### 已知美術限制

目前仍為程式化曲面與分層部件，尚無手繪紋理、精細雕刻、專業骨骼或動作捕捉。布料與皮革以霧面材質及造型區分，沒有布料物理。其餘四位武將尚無專屬模型。桌面／手機尺寸與觸控測試使用 Chromium 軟體 WebGL；實體手機的幀率、發熱與 GPU 相容性仍需裝置測試。

## V3.5：圓潤 Q 版收藏公仔美術

沿用 V3 的主公圖鑑、武將展示及 24 格棋盤，本版僅調整共用 Three.js 人物、美術材質、純視覺動畫與展示取景；未改動遊戲規則、存檔、移動時序或部署。

- **統一 Q 版比例**：以頭部主體計算約 2 頭身；大圓臉、放大雙眼與雙高光、圓潤臉頰、短手短腳，冠帽與羽翎保留角色差異。
- **八位角色精緻化**：劉備翠綠雙劍、曹操深藍玄甲、孫權金棕白袖、董卓紫紅圓肚；趙雲白銀甲與白披風、關羽長鬚綠袍與偃月刀、張飛粗眉黑鬚與蛇矛、呂布黑紅甲與雙紅羽翎。
- **模型材質**：角色專用霧面公仔、布料、皮革與柔和金屬配方；平滑刀刃輪廓、柔化短鬍鬚，修整衣擺甲片交疊。地形仍使用原有材質。
- **武器握持**：新增掌心握點、握拳手指、手腕反向補償；刀刃向外側配置，勝利舉武器時仍固定在掌心。單元測試以武器三角形到臉部橢球的距離，檢查八位角色的常用動畫姿勢。
- **動畫**：微微搖晃與呼吸、眨眼、短腿交替與輕彈跳、開心舉武器。招募由全身群組一起旋轉、輕跳並擺姿勢，不會只轉上半身或改變遊戲事件。
- **展示**：依角色與長兵器尺寸自動取景，模型更大；標題移到舞台下角，避免遮住長槍與刀刃。保留拖曳／觸控旋轉、縮放、資訊與動作切換。

本版無新增依賴或外部模型。仍是程式化曲面與簡化關節，尚非專業雕刻、手繪貼圖或布料物理；未宣稱達到商用遊戲美術資產品質。實體手機 GPU 的效能與發熱仍需裝置確認。
